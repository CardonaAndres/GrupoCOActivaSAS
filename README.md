# Grupo Coactiva S.A.S.

Sitio web de **Grupo Coactiva S.A.S.**, una agencia líder en recuperación de cartera en Colombia y América Latina.
El proyecto fue desarrollado con **Next.js**, **TypeScript** y **Tailwind CSS**, con enfoque en **rendimiento**, **SEO**, **accesibilidad** y una experiencia clara para el contacto con potenciales clientes.

---

## 🌐 Descripción

**Grupo Coactiva S.A.S.** es especialista en recuperación jurídica, prejurídica y extrajurídica de cartera vencida.
Este sitio web fue diseñado para reflejar sus valores de **ética**, **transparencia** y **compromiso**, facilitando el contacto directo con empresas que requieran apoyo profesional para la recuperación de activos.

El sitio incluye:

* Página principal con llamada a la acción y formulario de contacto.
* Sección de servicios detallados.
* Beneficios de contratar a Grupo Coactiva.
* Página **Sobre Nosotros** con misión, visión, valores y responsabilidad social.
* Información de contacto clara y accesible.
* Estructura optimizada para SEO y carga rápida.

---

## ⚙️ Stack tecnológico

* **Next.js** – Framework React para aplicaciones web con renderizado híbrido (SSR/SSG).
* **TypeScript** – Tipado estático para mayor mantenibilidad y escalabilidad.
* **Tailwind CSS** – Framework de estilos utilitarios para diseño rápido y consistente.
* **pnpm** – Gestor de paquetes rápido y eficiente.
